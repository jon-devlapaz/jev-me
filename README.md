# jev-me

Grill-me with Jev on each turn.

```bash
git clone https://github.com/jon-devlapaz/jev-me.git ~/.agents/skills/jev-me     # Cursor, Codex, Pi
git clone https://github.com/jon-devlapaz/jev-me.git ~/.claude/skills/jev-me    # Claude Code
git clone https://github.com/jon-devlapaz/jev-me.git ~/.hermes/skills/jev-me    # Hermes
git clone https://github.com/jon-devlapaz/jev-me.git ~/.pi/agent/skills/jev-me  # Pi
```

Type `/jev-me`. Export `TYPESAFE_API_KEY` for Jev.
